# Birthday Surprise Website — Fixed

This version includes the JavaScript inside `index.html`, so the gift button does not depend on a separate script file.

## GitHub Pages upload
1. Extract this ZIP.
2. Upload `index.html` and `style.css` directly into the repository root.
3. Commit the changes.
4. Go to Settings → Pages.
5. Select Deploy from a branch → `main` → `/(root)` → Save.
6. Open the published Pages URL. If the old version remains, refresh or try a private tab.

Do not upload only the ZIP file; extract it and upload the files inside.
