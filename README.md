# Birthday Gift Website 🎁

A small, mobile-friendly birthday surprise website made with plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Upload to GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your website link will appear in the Pages section.

## Change the messages
Open `script.js` and edit the `replies` object to change the three responses.

The birthday greeting automatically moves to the gift selection screen after 5 seconds.
